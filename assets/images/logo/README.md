# Logo Del Proyecto

Coloca aqui el logo con este nombre:

```text
neofit-logo.png
```

El frontend usa esta version transparente:

```text
neofit-logo-transparent.png
```

Ruta esperada por el frontend:

```text
assets/images/logo/neofit-logo.png
```

El backend lo servira como:

```text
http://127.0.0.1:8000/assets/images/logo/neofit-logo.png
```

Si reemplazas el logo original, vuelve a generar o reemplaza tambien `neofit-logo-transparent.png` para que no aparezca el fondo negro.
