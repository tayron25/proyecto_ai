# Audio Para Yoga

Coloca aqui la musica de Yoga con este nombre:

```text
yoga.mp3
```

Ruta esperada por el frontend:

```text
assets/audio/yoga/yoga.mp3
```

El backend la sirve automaticamente como:

```text
http://127.0.0.1:8000/assets/audio/yoga/yoga.mp3
```

Este audio esta pensado para durar aproximadamente 2 minutos. En la app web empieza al entrar al nivel de Yoga y continua aunque cambie de modulo; no se reinicia entre posturas.
