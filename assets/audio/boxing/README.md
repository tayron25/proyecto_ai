# Audio Para Box

Coloca aqui la musica de Box con este nombre:

```text
boxing.mp3
```

Ruta esperada por el frontend:

```text
assets/audio/boxing/boxing.mp3
```

El backend la sirve automaticamente como:

```text
http://127.0.0.1:8000/assets/audio/boxing/boxing.mp3
```

En la app web empieza al entrar al nivel de Box y continua aunque cambie de modulo; no se reinicia entre combos.
