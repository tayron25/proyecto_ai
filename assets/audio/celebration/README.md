# Audio De Aplausos U Ovacion

Coloca aqui el audio de aplausos/ovacion con este nombre:

```text
celebration.mp3
```

Ruta esperada por el frontend:

```text
assets/audio/celebration/celebration.mp3
```

El backend lo sirve automaticamente como:

```text
http://127.0.0.1:8000/assets/audio/celebration/celebration.mp3
```

Este audio suena una vez cuando aparece la pantalla final de resultados de Box, Yoga o Aerobico.
